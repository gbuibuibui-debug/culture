# 同心共绘 · 中华民族共同体 AI 数字长卷

## 运行

直接双击 `index.html` 即可离线浏览。建议使用 Chrome、Edge 或 Safari 的较新版本，桌面端 1440px 以上体验最佳。

项目不依赖 CDN、在线字体或外部脚本，文件夹整体打开即可运行。

## 四卷结构

- `embroidery.html`：第一卷「针线纹史」——五绣图谱、蝴蝶妈妈、纹样谱系、AI 刺绣短片。
- `dance.html`：第二卷「乐舞同心」——八方同舞、八舞种“舞之源 / 形 / 魂”、AI 动作长卷影片。
- `sound.html`：第三卷「声之源流」——四段式声音影片叙事、五件核心乐器、悬浮声波可视化。
- `festival.html`：第四卷「人间烟火」——中央篝火、八节庆节点、图文内页、AI 节庆总览影片。

## 视频说明

四个视频展区均采用动态长卷式展映界面：点击朱砂播放印后，画面会缓慢推镜、光影流动并显示进度线。


## 视觉素材

第二卷首页直接使用提供的《一舞承千载 · 万象共中华》工笔重彩图。其余三卷采用项目内原创 SVG 长卷背景，以宣纸肌理、矿物青绿、赭石、朱砂、金线和工笔线描统一视觉语言；无网页外链图片。
